# Jetons de design

Source unique : `packages/ui/src/tokens`. Chakra, Ant Design, Tailwind et le
SCSS lisent ces valeurs ; ne pas écrire de couleur en dur ailleurs. Cette page
est générée à partir des jetons : elle suit leurs changements.
